# The Ledger Hall

A medieval-themed companion dashboard for betting chat, open wagers, trial records, recent results, and live battle reports.

## Active entry points

- `index.html` — current repository-root preview used by GitHub Pages.
- `docs/integration-review/simplified-concept-v1/index.html` — locked desktop v65 direction and the active development baseline.
- `docs/integration-review/simplified-concept-v1/desktop-final-review.html` — side-by-side comparison with the canonical design reference.

## Current development baseline

The desktop v65 prototype owns its styles, production artwork, and live-data adapter inside `docs/integration-review/simplified-concept-v1/`. Odds Snapshot remains visually frozen and outside the live-data contract until its replacement is selected.

Mobile work and final Battle Report team logos are intentionally deferred.

## GitHub Pages

Publish from the `main` branch and repository root in **Settings → Pages**. The root preview and the v65 development baseline are both retained while integration continues.
