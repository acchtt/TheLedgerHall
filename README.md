# Merchant Hall — standalone GitHub Pages demo

This branch publishes the Merchant Hall visual prototype only. It does not contain the production TheLedgerHall app or contact its Cloudflare D1 database.

- Three design options: Ledger Desk, Counting Room and Reserve Chamber.
- Desktop/mobile responsive layouts.
- Illustrative data and preview-only payment dialog.
- No local or remote persistence. Navigation outside the overview is intentionally nonfunctional.

**Source branch:** [demo/merchant-hall](https://github.com/acchtt/TheLedgerHall/tree/demo/merchant-hall/prototypes/merchant-hall).

**Published link when GitHub Pages is enabled with branch gh-pages and /(root):** https://acchtt.github.io/TheLedgerHall/

To configure once: repository Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root) → Save.

This demo branch is separate from production main. Do not merge unless the design has been reviewed and approved.
