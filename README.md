# The Ledger Hall

A medieval-themed companion dashboard for betting chat, open wagers, trial records, recent results, and live battle reports.

## Files

- `index.html` — page layout
- `chat.css` — parchment and carved-wood theme
- `chat.js` — sample ledger data and interactions

## GitHub Pages

Publish from the `main` branch and repository root in **Settings → Pages**.

The current sample data is stored in the `state` object at the top of `chat.js`. It can later be replaced with a shared ledger data source.
